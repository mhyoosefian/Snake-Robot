# Snake Robot

MATLAB code for deriving and simulating the equations of motion of a four-link wheeled snake robot. The wheels at the center of mass of each link prevent sideways slip, which gives four nonholonomic constraints on six generalized coordinates, and the joints carry torsional springs. The equations are solved with eight methods: integrated multipliers, augmented, elimination, embedding, modified Lagrange, Greenwood, Gibbs–Appell and Kane. The methods are compared in terms of accuracy (energy conservation and constraint violation), run time and the size of the matrix that must be inverted. A 3D animation of the simulated motion is also included.

**For an explanation of the method and the results, see the project page:**
**https://mhyoosefian.github.io/projects/snake-robot/**

## Requirements

- MATLAB (tested with R2022b)
- Symbolic Math Toolbox (only for `Symb_Deriv.m`)

## How to use the code

- **Compare the methods:** run `RunMe.m` and choose a method from the menu, then choose between plots (generalized coordinates, constraint violation and energy error) and a simple 2D animation.
- **3D animation:** run `RunAnimation.m`. It simulates the robot with the method set at the top of the file and plays a 3D animation that follows the robot, with the wheel tracks drawn on the floor. Set `saveVideo = 1` to also save it as an MP4 file; the simulation time and playback speed are set there too.
- **Derivation:** `Symb_Deriv.m` derives the equations symbolically. The `matlabFunction` lines that write the generated functions (`MassMat.m`, `A_Aug.m`, `Bpr_Ml.m`, ...) are commented out; uncomment the ones for a method to regenerate its files.

## Repository structure

```
RunMe.m            simulation of the eight methods (plots or a 2D animation)
RunAnimation.m     simulation and 3D animation
animateSnake.m     draws and plays (or records) the 3D animation
Symb_Deriv.m       symbolic derivation of the equations of motion
IntMulDyn.m, AugmntDyn.m, ElimDyn.m, EmbdDyn.m, ModlagDyn.m, GreenDyn.m, GibssDyn.m, KaneDyn.m
                   state derivatives of the eight methods
other *.m files    functions generated by Symb_Deriv.m
```
